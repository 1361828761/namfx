## 1. 信号链拓扑（Analog Is Not Dead 分析）

```
吉他输入
  → 输入网络（R1=1M 参考 + C1=22n 耦合 + R2=10k + R3 限流；JFET Q4=2N5457 输入缓冲，输入阻抗 ≈330k）
  → 第一增益级（TL082 非反相）：
      - 增益 = (Drive 电位器 1M + R8=10k) / R5 设定（Drive 0..1M → 增益范围由 R5 决定）
      - C6=220p 反馈电容：限制频响 + 稳定增益级（高频滚降）
      - C4=1n：限制低音被放大（低切）
      - R9=39k：限制进入削波级的电流 + 削波级前高频削减（R9+C7）
  → 削波级（关键）：
      - Q1/Q2 = 2N7000 MOSFET × 2（反并联，当"慢斜率二极管"用）
      - v4+ 版本：D1 = 1N34A 锗二极管并联（不对称削波）
      - 特征：硬削波但边缘比 Boss BD2 平滑；不对称（正 +5V / 负 -3.5V，v4）
  → C7=1u 耦合
  → 第二增益级（TL082 非反相，反馈回路两电阻设定固定增益）
  → 音调网络（treble bleed）：
      - TONE = B10K 电位器 + 电容到地（高频滤波）
      - HP/LP 开关（SW3）：并联 R14=1k（高/低增益模式）
  → VOL = A100K 音量电位器（音频锥）→ 输出
```

### 1.1 关键特征（OCD 音色机制）

1. **MOSFET（2N7000）当二极管**：不是指数二极管——平方律导通（Vth≈2V），斜率比二极管缓 → "慢斜率"硬削波 → 平滑边缘、动态保留
2. **锗二极管不对称**（v4）：负半周 1N34A（拐点 ~0.3V）先削 → 正 +5V / 负 -3.5V 不对称 → 偶次谐波
3. **双增益级 + 削波**：第一级高增益（Drive 控制）→ 削波 → 第二级固定增益（音色整形）
4. **中频强调**：音调网络 + 低切 → "在混音中突出"；总增益 ~50dB
5. **9V/18V 双电源**：18V 更高 headroom（运放不饱和）——数字模型 AC 域
6. 参数仅三个：**Drive（A1M 音频锥）/ Tone（B10K）/ Volume（A100K 音频锥）** + HP/LP 开关（v1 简化不做）

## 3. 数字实现要点

| 项 | 事实 | 来源 |
|---|---|---|
| 削波器件 | 2N7000 平方律：i = K·(v-Vth)²（|v|≥Vth），Vth≈2V；非指数二极管 | Analog 分析（"MOSFETs used as slow-slope diodes"） |
| 不对称 | v4：+5V / -3.5V（1N34A 锗二极管在负半周路径） | Analog 仿真图（voltage saturation curve） |
| 削波前增益 | 第一级 (10k + D·1M)/R5，总增益 ~50dB | Analog 分析 |
| 音调 | 一阶低通（B10K pot + C8 47n 到地），treble bleed | Analog 分析 + BOM |
| 中频强调 | 低切（C4）+ 音调网络 | Analog 全局频响图 |

### 结构建议（namfx 数字实现，v4 风格 = 含不对称）

| Stage | 建议方法 | 依据 |
|---|---|---|
| 输入缓冲 | 直通（JFET 缓冲增益 1，平坦） | Analog（缓冲增益 1） |
| 第一增益级 | 非反相：G1 = 1 + (10k + D·1M)/R5；C6 反馈帽高频滚降；C4 低切 | Analog + BOM |
| 削波级 | **解析 MOSFET 对**：i = K·(v-Vth)²·sign，不对称拐点（正 2.0V / 负 1.4V 近似锗二极管效应），与 R9=39k 串联求闭式解；v 输出经 C7 耦合 | Analog + BOM（推导） |
| 第二级 | 固定增益 1 + R11/R12 | Analog + BOM |
| 音调 | 一阶低通（(1-t)·10k + 源阻抗）·47nF，系数随 Tone 平滑 | Analog + BOM |
| 输出 | VOL 增益（音频锥 0..1）| BOM |

> R5 缺失：取 R5=4.7k（G1 = 3.1×..216×，总增益 D=1 时 ≈54dB，与 Analog "~50dB" 一致）；K 值由削波电压校准：K·R9≈1 → 削波节点 ~3-5V，匹配 Analog 转移曲线（正 +5V / 负 -3.5V）。

## 5. 明确的"未找到 / 不可达"项（待后续验证）

1. **R5 元件值**：BOM 未列。本文推导 R5=4.7k（增益匹配 ~50dB），待第三方拆解图复核。
2. **2N7000 的等效 K 值**：数字模型校准值（K·R9≈1），非数据手册值；2N7000 当二极管（栅漏短接源跟随）的有效导通特性远缓于数据手册的开关特性。
3. **C4 低切的具体转折频率**：C4=1n 与未列元件组合，本文取等效低切 ~400Hz（行为级），待验证。
4. **v4 锗二极管在削波网络中的具体接法**：Analog 图（+5V/-3.5V 不对称）与 BOM（D1 位置）一致但接线细节未明；本文以"负半周拐点降低"等效建模（负侧 Vth=1.4V）。
5. **HP/LP 开关**：v1 不实现（参数膨胀，音色差异小）。
