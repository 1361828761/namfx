## 1. 电路事实（Architolk，Boss OC-2）

### 1.1 基本信息

- 1982 年推出，2003 年被数字 OC-3 取代；纯模拟电路
- 子电路分解：输入缓冲 → **分析器**（跟踪输入基频）→ **子八度生成器**（×2 份，-1 与 -2 八度）→ 输出混合

### 1.2 各级电路

| 级 | 电路 | 说明 |
|---|---|---|
| 输入缓冲 | 虚拟地 + 放大 ×5；高通（转折极低，>50Hz 相位/幅度无影响） | 单电源 9V 虚拟地 |
| 分析器 | 低通（滤基频）→ 峰值检测（LM324 运放）→ 比较器 → 方波（与输入峰值 90° 相移）；CD4013 第一部分生成跟随峰值的方法 | 跟踪输入基频 |
| 二分频 | CD4013 第二部分：半频方波；BA634（简化版 CD4027）再二分频 → -2 八度 | 触发器翻转在峰值处（"对 440Hz 很好，220/880Hz 有偏差"——原文记载的跟踪精度限制） |
| 子八度生成 | 输入经电容+二极管提升到虚地以上，与 ±0.5 方波相乘（晶体管开关：关 = ×0.5，开 = ×−0.5） | **波形乘法**——sub 保留输入波形音色 |
| 相位对齐 | "控制信号必须与输入信号相位正确，否则信号在错误位置被切 → 波形折叠，产生更多谐波" | 关键性约束 |

### 1.3 通用路线对比（IPFS wiki）

- 八度下通用做法：信号转方波 + 触发器二分频 → "buzzy synthesizer like tone"（MXR Blue Box 路线）
- **OC-2 的波形乘法路线更圆润**（sub = 输入波形交替反相，非方波）

## 2. 数字实现要点

| 项 | 事实 | 来源 |
|---|---|---|
| 跟踪 | 分析器跟踪基频（峰值/过零）→ 二分频控制信号 | Architolk |
| 二分频 | 触发器在信号特征点翻转 → 半频方波 | Architolk |
| 子八度 | 输入 × ±0.5 方波切换（波形乘法，非方波合成） | Architolk |
| 相位 | 控制信号与输入错相 = 波形折叠谐波 → 必须对齐 | Architolk |
| -2 八度 | 二级二分频（BA634/CD4027） | Architolk（v1 不建模，见 §4） |

### 结构建议（namfx 数字实现，行为级）

| Stage | 建议方法 | 依据 |
|---|---|---|
| 触发 | 输入上升沿过零检测（|x| > ε 迟滞防抖）翻转二分频状态 | Architolk 触发器（过零与峰值触发对 sub 波形等价，见下文推导） |
| 子八度 | sub = x × flip（flip = ±1 半频），每两输入周期反相一次 → sub = 输入波形交替反相，基频 f/2、幅度保持 | Architolk 波形乘法 |
| 整形 | tone 0..1 → 2 阶 Butterworth 低通 300Hz..2kHz（OC-2 输出圆润感） | 行为参数 |
| 混合 | out = dry·(1−mix) + sub·mix，×level | OC-2 Direct/Effect 混合惯例 |
| -2 八度 | v1 不建模（二级二分频 + 独立混合，后置） | Architolk（范围控制） |

> 触发相位推导：flip 在输入过零处（或峰值处）翻转，sub 均为"完整正弦周期交替反相"拼接——两者对 sub 波形等价（仅相位偏移），故行为级用过零触发（连续、无跳变）。

## 4. 明确的"未找到 / 待落地"项

1. **-2 八度（四分之一频）**：OC-2 双 sub（-1/-2 各带电平）；v1 只做 -1，-2 后续增量（二级二分频即可）
2. **峰值触发 vs 过零触发**：OC-2 实际用峰值（90° 相位）；行为级用过零（波形等价，推导见 §2）；若听感需要可加相位偏移参数
3. **跟踪精度**：原文记载 220Hz/880Hz 处方波边沿偏移（"太早/滞后"）；v1 过零触发无此误差，此为行为级与硬件的差异点
4. **输入缓冲 ×5 放大 + 二极管钳位细节**：v1 不建模（增益由 level/mix 承担）
