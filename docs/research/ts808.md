## 1. 信号链概览（A）

### 1.1 整机拓扑（三来源一致）

```
吉他输入
  → 输入缓冲 (射极跟随器, 增益≈1, 高输入阻抗)
  → 削波放大级 (非反相运放 + 反馈环内二极管限幅, 增益 ≈12~118 可调)
  → 音调控制 (1k+0.22µF 低通 → 20k 音调电位器有源级, 增益≈1) → 音量电位器 (100k 音频)
  → 输出缓冲 (射极跟随器) → 输出
```

- geofex：块图 = Input buffer → Clipping Amp → Tone/volume control → Bypass switching → Output buffer；TS 全系共用此结构（TS10 例外点见 §2.2）。
- DAFx2007 §4：Overdrive 块图 = 高通滤波 → （输入信号 ⊕ 高通滤波后削波信号之和）→ 低通 tone 滤波 → 输出缓冲内高通。
- DAFx2007 §4 引言明确：削波后接 tone 低通，**tone 在削波之后**（TS-808-Ultra 实现同样：clipping → tone）。
- 电源：9V 电池/外部电源；4.5V 偏置由两个等值电阻分压产生，大电解电容去耦为 AC 地（geofex）。

来源：
- http://www.geofex.com/Article_Folders/TStech/tsxtech.htm
- http://dafx.de/paper-archive/2007/Papers/p189.pdf （§4, Fig.13）
- https://github.com/JamesStubbsEng/TS-808-Ultra/blob/master/Source/PluginProcessor.cpp （处理顺序）

### 1.2 各 stage 功能

| Stage | 功能 |
|---|---|
| 输入缓冲 | 射极跟随器（2SC1815），高输入阻抗（≈510k，由 510k 偏置电阻主导），增益 1 |
| 削波放大级 | 非反相运放，V⁻ 支路 4.7k+0.047µF 构成高通增益（转折 720Hz，削低音→"不浑浊"）；反馈环内 51k+500k Drive 电位器 ∥ 51pF ∥ 反向并联二极管对；二极管导通时增益骤降→软削波 |
| 音调控制 | 1k→0.22µF 对地低通（723Hz，-6dB/oct）→ 20k 音调电位器横跨运放两输入端，滑臂接 220Ω+0.22µF 串联 RC 到地（转折≈3.2kHz）；运放为缓冲（增益1）；100k 音量电位器（音频锥） |
| 输出缓冲 | 射极跟随器（10k 射极电阻，4.5V 偏置）；TS808 特有：100Ω 串联 + 10k 并联电阻输出网络（TS9 为 470Ω/100k） |

来源：geofex（同上 URL）。

### 2.1 WDF 分解（Duarte & Chowdhury 法，TS-808-Ultra 实现）

削波级按论文 p.7 拆成 3 个串联 WDF 子网（来源：ClipWDFa/b/c.h）：

| 子网 | 元件 | 功能 |
|---|---|---|
| a | C2=1µF，RA=220Ω，R5=10kΩ（串联；源内阻 1Ω 理想） | 电压入→电压出（输入高通网络） |
| b | R4=4.7kΩ 串 C3=47nF | 电压入→电流出（V⁻ 支路 Zi，把 V⁻=V⁺ 的电流算出） |
| c | 电流源（内阻 51kΩ+Drive 电位器）∥ C4=51pF ∥ 二极管对；二极管模型 1N914 对管 @25°C，Is=25nA | 电流入→电压出（反馈网络等价） |

二极管为反向并联对（DiodePairT），削波在反馈节点（= Vo−Vi）上 ±0.6V 处钳位。

## 4. DAFx2007 音调电路模拟传递函数（D）

### 4.1 论文信息（已核实）

**标题**：《Simplified, Physically-Informed Models of Distortion and Overdrive Guitar Effects Pedals》
作者：David T. Yeh, Jonathan S. Abel, Julius O. Smith（CCRMA, Stanford）
出处：Proc. of the 10th Int. Conference on Digital Audio Effects (DAFx-07), Bordeaux, France, Sept 10-15, 2007, pp. 189-196（p189.pdf）
（注：任务描述猜测的标题 "Understanding the TS9/TS808..." 不成立，已核实为上述标题）

### 4.2 §4.3 的传递函数（Eq. 24）

二阶模拟带通/低通（变量系数）：

```
Vo/Vi = [(Rl·Rf + Y) / (Y·Rs·Cs)] · (s + W·ωz) / [(s + ωp)(s + ωz) + X·s]
```

其中：

```
W  = Y / (Rl·Rf + Y)
X  = [Rr/(Rl+Rr)] / [(Rz + Rl‖Rr)·Cz]
Y  = (Rl+Rr)·(Rz + Rl‖Rr)
ωz = 1 / [Cz·(Rz + Rl‖Rr)]
ωp = 1 / [Cs·(Rs‖Ri)]
```

元件值（论文 §4.3 明示）：

```
Rf = 1kΩ   Rr = (1−T)·20kΩ   Rl = T·20kΩ   Rz = 220Ω   Cz = 0.22µF
Ri = 10kΩ  Rs = 1kΩ          Cs = 0.22µF
T ∈ (0,1) 控制低通截止
```

§4.3 结论：二阶变系数传递函数；幅频响应本质为低通特性（Fig.16）。§4.3 开头声明该网络可按理想运放规则（nodal analysis）完整求出——即 Ultra README 所称 "tone circuit analog transfer function ... section 4.3 on page 6" 的出处。

### 4.3 数字双二阶系数（TS-808-Ultra 实现，直接对应上式）

（来源：ToneStage.cpp，代码注释引用 ccrma.stanford.edu 镜像 yeh07_dafx_distortion.pdf page 6）

模拟系数（与 Eq.24 逐项对应）：
```
alpha = (Rl·Rf + Y) / (Y·Rs·Cs)
b(s) = [0, alpha, alpha·W·ωz]         → H(s) = alpha·(s + W·ωz) / [s² + (ωp+ωz+X)s + ωp·ωz]
a(s) = [1, wp + wz + X, wp·wz]
```
→ 数字系数由双线性变换得到；Ultra 用 `chowdsp::Bilinear`，先求模拟极点频率 wc 做补偿：
`K = wc==0 ? 2·fs : wc / tan(wc/(2·fs))`。
⚠️ 矛盾记录：Ultra README 称 "No frequency warping was used in the plugin, as it was found no frequency warping produces a better sound"，但代码 ToneStage.cpp 实际计算了 wc 并用于 K。README 与代码表述不一致——实现时以代码为准或自行验证。

- https://github.com/JamesStubbsEng/TS-808-Ultra/blob/master/Source/dsp/ToneStage.cpp
- https://raw.githubusercontent.com/JamesStubbsEng/TS-808-Ultra/master/Source/dsp/ToneStage.cpp

### 结构建议（数字实现）

| Stage | 建议方法 | 依据 |
|---|---|---|
| 输入缓冲（射极跟随器） | 直通/忽略（增益1、平坦频响，DAFx 声明可忽略） | DAFx2007 §3.1（对应 Distortion 段；TS808 输入级同为缓冲） |
