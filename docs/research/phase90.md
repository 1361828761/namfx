## 1. 电路拓扑（1974 第一版 MXR Phase 90）

```
吉他输入
  → 输入缓冲级（运放 + RC 噪声滤波）
  → 相位移动级 = 4 个相同的相位移动单元串联（每个单元 = 一阶全通滤波器）
     每个单元：运放 + 2N5952 JFET（压控电阻 R_JFET）+ 电容 C2
     → LFO 三角波调制 JFET 栅压 → R_JFET 变化 → 断频移动
  → 输出级：干声 V1 + 移相声 V2 相加（产生陷波）+ 共射放大器（补增益）+ 22Hz 高通
```

### 1.1 关键特征（相位音色机制）

1. **4 级一阶全通串联**：全通只改变相位不改变幅度；每级最大相移 −π，4 级合计最大 −4π（F·π，F=4）
2. **陷波**：干声与移相声相加，在移相总相位 = 奇数个 π 处对消 → 陷波；4 级 → 带内 **F/2 = 2 个陷波**
3. **LFO 扫频**：LFO 经 JFET 栅压调制 R_JFET → 断频摆动 → 陷波上下移动——"旋转/喷气"音色
4. **1974 原版无反馈电阻**：现代版本在第二单元运放负端与末级输出间加了反馈电阻（音色控制）；第一版没有 → 本模型不加反馈参数
5. **JFET 非线性失真**（Cytomic 强调）：大信号下 JFET 变阻器本身产生可观失真，甚至泄漏进栅极干扰 LFO——v1 行为级不建模（见 §5.3）

## 2. 元件值（DAFx24 论文，参考 electrosmash 原理图）

### 2.1 输入缓冲级

| 元件 | 值 | 说明 |
|---|---|---|
| R1 | 10kΩ | 输入电阻 |
| C1 | 0.01µF | 与 R1 组成 RC 滤除交流声 |
| R2 | 470kΩ | 偏置 |
| Vref | 5.1V | 参考电压（9V 供电中点偏置） |

### 2.2 相位移动单元（×4，每个 = 一阶全通）

| 元件 | 值 | 说明 |
|---|---|---|
| R3 = R4 | 10kΩ | 运放外围电阻 |
| R5 | 24kΩ | 与 JFET 串联决定断频 |
| C2 | 47nF | 全通电容 |
| Vref | 5.1V | 参考电压 |
| Q1 | 2N5952 JFET | 压控电阻 R_JFET（漏源电阻） |

**单元传递函数**（Z 域，一阶全通）：

```
A(z) = (c1 + z⁻¹) / (1 + c1·z⁻¹)
c1 = −(1 − tan(ωb·Ts/2)) / (1 + tan(ωb·Ts/2))  ≈ −1 + ωb·Ts    （Ts = 采样周期）
```

**断频公式**（断频处单级相移 = −π/2）：

```
ωb = tan(φss/2) / ((R5 − R_JFET)·C2)
```

- 断频（−90° 点）随 R_JFET 上升而上升：R_JFET → 0 时 f_b ≈ 1/(2π·24k·47n) ≈ 141Hz；R_JFET 接近 R5=24k 时 f_b → 高频（数 kHz 以上）
- 4 级合计相移 = 单级相移之和；陷波频率 = 单级相移 −45° 处（4×(−45°) = −180°），即 f_notch ≈ 0.4142 × f_b

### 2.3 输出级

| 元件 | 值 | 说明 |
|---|---|---|
| R6 | 150kΩ | 混合网络电阻 |
| R7 | 56kΩ | 混合网络电阻 |
| C3 | 47nF | 混合网络电容 |
| 高通 | fc = 22Hz | 去除输出直流 |

干声 V1 与移相声 V2 经 R6/R7 混合相加 → 陷波产生；共射放大器（反相 + 补增益）在数字模型中用后置负增益等效（论文将 BJT 非线性视为可忽略）。

## 3. 数字实现要点

| 项 | 事实 | 来源 |
|---|---|---|
| 相位单元 | 一阶全通 A(z) = (c1+z⁻¹)/(1+c1·z⁻¹)，c1 由断频映射（式 8/9） | DAFx24 |
| 级数 | 4 级串联，最大总相移 −4π；带内陷波数 = F/2 = 2 | DAFx24 |
| 扫频 | LFO → R_JFET → 断频移动 → 陷波扫动；断频公式 ωb = tan(φss/2)/((R5−R_JFET)·C2) | DAFx24 |
| 混合 | 干声 + 移相声相加（50/50 等效）→ 陷波；输出 22Hz 高通去直流 | DAFx24 |
| 反馈 | 1974 原版无反馈电阻（现代版才有，作音色控制）→ 不加 | DAFx24 |
| LFO 波形 | 三角波（论文仿真设定；原踏板待验证） | DAFx24 |

### 结构建议（namfx 数字实现，行为级）

| Stage | 建议方法 | 依据 |
|---|---|---|
| 全通级 | 4 级一阶全通级联，系数 c1 逐样本由断频 f_b 映射：t = tan(π·f_b/fs)，c1 = (1−t)/(1+t) | DAFx24 式 8/9（符号约定对齐） |
| 扫频 | 断频指数扫频 f_b ∈ [300Hz, 3500Hz]（行为默认值，落在电路可行扫频域内：R_JFET ∈ [~200Ω, ~23kΩ] 时 f_b ≈ 141Hz..数 kHz） | DAFx24 式 10 推导 |
| LFO | 三角波 0.05..2Hz（rate 参数 0..1 映射） | 论文仿真 2Hz 三角波 + 行为参数惯例 |
| 混合 | dry·0.5 + wet·0.5（等效于干声+移相声相加），level 参数作输出增益 | DAFx24 输出级 |
| 高通 | v1 不建模 22Hz 高通（仅去直流，音频带外） | — |
