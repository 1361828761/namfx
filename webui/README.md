# NAMFX WebUI — 使用与验收

> 设计基线见 [DESIGN.md](DESIGN.md)。本文件是**验收指引**：怎么跑起来、看什么、试什么。

## 1. 快速开始

### 方式 A：直接体验（浏览器演示模式，无需构建）

```powershell
cd webui\www
python -m http.server 8765
# 浏览器打开 http://127.0.0.1:8765/
```

无后端也完整可玩：内置模拟引擎（`?demo=1` 强制，宿主不可达自动回退），可试界面和编辑交互。
演示模式不会处理麦克风或系统音频；真实音频处理需要桌面音频宿主，或后续的 WebAssembly 音频目标。

### 方式 B：真实引擎（C++ 宿主，推荐验收）

```powershell
# 构建（本机 cmake 全路径示例；或 VS Developer PowerShell 里直接 cmake）
D:\study\vc\vsiualstudio\Common7\IDE\CommonExtensions\Microsoft\CMake\CMake\bin\cmake.exe --build build\debug --target namfx_web

# 启动宿主（默认 0.0.0.0:8810；本机验收建议 --bind 127.0.0.1）
build\debug\webui\Debug\namfx_web.exe --port 8810 --bind 127.0.0.1
```

浏览器打开 **http://127.0.0.1:8810/** —— 页面自动连接宿主（右上角绿点 = 已连接），
预设/链/参数/场景全部来自真实引擎（`EngineHost` + `namfx_core`），改动即推送到引擎。

> 独立宿主和 WebView2 壳都接入 JUCE 原生音频后端，启动时优先尝试 ASIO；设置页可切换
> WASAPI/ASIO、设备、采样率和缓冲。演示预设加载自 `core/preset/demo/`，用户数据在
> `Documents\namfx\`（预设/模型/IR）。

### 方式 C：浏览器音频调试（WASM，无 C++ 宿主）

接琴调试 WebUI 的路径：浏览器直接运行编译成 WASM 的 `core`（全部内置 DSP/WDF +
NAM 模型 + IR 卷积），不启动任何 C++ 进程。

```powershell
# 先在当前终端激活 Emscripten SDK
call <emsdk>\emsdk_env.bat

# 配置 + 构建 WASM 音频目标
cmake --preset wasm-debug
cmake --build --preset wasm-debug --target namfx_wasm

# 启动静态 WebUI
cd webui\www
python -m http.server 8765
```

浏览器打开 `http://127.0.0.1:8765/?wasm=1`，点击顶部「启动音频」并允许麦克风权限。
修改 C++ DSP 后只需重新构建 `namfx_wasm` 并刷新浏览器，不需要打包 EXE。

### 方式 D：WebView2 桌面壳（正式形态，推荐验收）

界面与浏览器形态完全相同，但音频走原生 WASAPI/ASIO，延迟与桌面编辑器一致。

```powershell
# 构建 Release 壳并组装自包含目录
powershell -ExecutionPolicy Bypass -File tools\package-webui.ps1

# 运行
build\namfx-webui-release\NAMFX.exe
```

打包目录包含 `NAMFX.exe`、`WebView2Loader.dll`、`www/`（前端）与 `presets-demo/`
（出厂预设），可整体拷贝到其他 Windows 机器运行（需已装 WebView2 Runtime，Win10/11 默认带）。

## 2. 界面地图（Helix Native 风格）

```
┌ 标题栏：NAMFX 标识 · 工作上下文 · 拖动区 · 连接状态 · [—][□][✕]（壳形态）      ┐
├ 应用栏：当前预设(ABC编号) | A/B+存 | 撤销/重做 | 调音器 | [启动音频] | 总旁路 | 静音 | 电平表 | 性能 | 锁定 | 设置 ┤
├ 场景条：1-8 场景按钮 + 命名 + 存储 + L CC（MIDI 学习）─────────────────────────────┤
├──────────┬────────────────────────────────────────────────────────────────────────┤
│ 预设侧边栏 │ 效果链（上半区）：IN ↘ 01..06 ↘ 折返 ↘ 07..12 ↘ OUT                 │
│ 01A/B/C…  │   12 个固定视觉槽位；上排 1-6，下排 7-12                       │
│ 02A/B/C…  │   拖到已有模块交换，拖到空槽移动；双击模块旁路/启用                 │
│ （ABC分组）├────────────────────────────────────────────────────────────────────────┤
│ 搜索/保存/ │ 工作台 tab：编辑(默认) | 演出 | 模型库 | 控制源 | 系统                 │
│ 导出/导入  │   编辑 = 分类栏(过载/压缩/调制/延迟/混响/EQ/门限/音高/箱头/箱体/工具) │
│            │           │ 模块列表 │ 参数面板（顶栏=名称+旁路+mix+移动+删除）       │
├──────────┴────────────────────────────────────────────────────────────────────────┤
└ 状态栏：消息 · xrun · 引擎版本/档位 ────────────────────────────────────────────────┘
```

- **预设编号**：ABC 三预设一组 —— `01A/01B/01C/02A…`（文件名带 `NN[A-C]_` 前缀则优先采用），出厂与用户预设编号连续；侧边栏顶部可搜索。
- **旋钮**：竖向拖动调节（Shift 细调）、滚轮、双击输入数值、右键菜单（重置默认/随机微调/MIDI 学习）。
- **音色链**：固定 12 个视觉槽位，线路为上排左到右、右侧下折、中间向左、左侧下折、下排左到右；视觉空槽不改变音频引擎的连续处理顺序。
- **拖拽**：整个模块卡片、模块图标、箱头和箱体都可作为拖拽起点；已有槽位执行交换，空槽保留空洞布局。
- **快捷键**：`1/2` A/B · `Ctrl+Z/Y` 撤销/重做 · `T` 调音器 · `M` 静音 · `Alt+1..8` 场景 · `Ctrl+K` 搜索预设。
- **调音器**：全屏仪表（演示模式可开"模拟信号"看效果；壳/WASM 形态接真实输入）。

## 3. 验收清单（建议逐项试）

1. **预设浏览**：左侧出厂/用户预设按 ABC 分组，顶部可搜索，点击加载，应用栏显示编号+名称，链刷新。
2. **链编辑**：点空槽 `+` → 编辑页选模块添加；卡片/图标视图切换；12 个固定槽位；
   双击模块格直接旁路/启用；拖动模块交换或移入空槽；箱头/箱体选择 NAM 模型/IR（模型库页导入
   `.nam`/`.wav`，也可拖文件进窗口；WASM 形态资产进浏览器内存）。
3. **参数编辑**：点链上格子 → 下方旋钮网格；拖动/滚轮/双击/右键；旁路开关与干湿 mix 在
   面板顶栏。改动后应用栏出现琥珀 dirty 点。
4. **场景**：点场景按钮回忆；「存储」把当前音色存入选中槽；命名 ≤8 字；跨场景差异琥珀角标。
5. **A/B + 撤销**：首次按 A/B 存入当前音色，再按切换对比；「存」按钮可重新存入；
   切换预设后 A/B 清空；`Ctrl+Z/Y` 撤销/重做（拓扑级）。
6. **演出面板**：Master/InGain/三段 EQ/Low Cut/High Cut/静音/总旁路滑杆即时生效。
7. **MIDI 学习**：参数右键或场景条 L CC 进入学习态 → 壳/WinMM 宿主下转动踏板 CC 即完成绑定
   （演示模式用"发送 CC"模拟）。
8. **调音器**：`T` 全屏，演示模式开"模拟信号"看指针/音名。
9. **导出/导入预设**：侧边栏底部；导出为 JSON（下载），导入解析后存入用户预设。

## 4. 已知边界（验收时知悉）

- **单实例约定**：同一模块不可重复入链（引擎控制路由按模块 ID 寻址，重复实例参数会误路由；
  添加时拒绝并提示）。
- **浏览器 WASM 延迟**：`?wasm=1` 形态约 10-25ms 量级（AudioWorklet + 设备缓冲），适合接琴
  调试；正式演出用 WebView2 壳（原生 WASAPI/ASIO，5-8ms）。
- **浏览器演示无声**：`?demo=1` 只模拟引擎状态，不是 NAM/DSP/IR 的真实处理路径。
- **参数撤销粒度**：undo/redo 覆盖预设加载/链拓扑/场景，参数微调不入栈（避免拖动刷栈）。
- **MIDI 输入**：WinMM 宿主/壳已接真实 CC 学习；浏览器形态无 MIDI。
- **设置页**：独立宿主和壳形态可选择采样率/缓冲/音频设备；浏览器形态由浏览器/系统决定，
  不支持直接枚举或加载 ASIO。
- **资源目录**：项目内置资源放在 `modles/nam/`、`modles/ir/`；用户导入资源放在
  `Documents\namfx\models\`、`Documents\namfx\irs\`。
